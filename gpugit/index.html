GPUGIT

One NVIDIA card. One job. A first reply inside ten minutes, or a plain reason why not. This page does not run a model. Checked 28 Nov 2026. No measured tokens per second.

01 · Install

Put the check on the machine.

The script looks for nvidia-smi and prints the pinned download. It does not install a driver. UNTESTED on hardware.

curl -fsSL https://raw.githubusercontent.com/Blockchains/gpugit/main/install.sh | sh

02 · The only decision

Chat, code, or a small API.

Images, video, and voice stay refused until a checkpoint has a sourced file size. ComfyUI and whisper.cpp are forked as engines. Their weights are not pinned.

03 · The only pinned weight

Qwen2.5 1.5B, Q4_K_M.

Labeled 986 MB on the Hugging Face card. Licence on that card: apache-2.0. Engine: llama.cpp, MIT. Working-set floor 4 GB is an estimate. SHA-256 was not copied, so it is not pinned.

huggingface-cli download bartowski/Qwen2.5-1.5B-Instruct-GGUF --include "Qwen2.5-1.5B-Instruct-Q4_K_M.gguf" --local-dir ./models

Start flags are not invented here. Use the upstream llama.cpp quick start. UNTESTED.
