GPUGIT

One NVIDIA card. One job. A first reply inside ten minutes, or a plain reason why not. This page does not run a model. No measured tokens per second.

Install

The script checks for nvidia-smi and prints the pinned download. It does not install a driver. UNTESTED on hardware.

curl -fsSL https://raw.githubusercontent.com/Blockchains/gpugit/main/install.sh | sh

Pinned jobs

Chat and a small localhost API use Qwen2.5-1.5B-Instruct Q4_K_M, labeled 986 MB, apache-2.0, on llama.cpp. Source: Hugging Face card. The 4 GB working-set floor is an estimate.

Voice uses whisper.cpp tiny: 75 MiB on disk, about 273 MB in memory, from the project README. MIT.

Images and video are refused. ComfyUI is forked, but no checkpoint size was verified.

Clock at 100 Mbps

Chat file, design targets, not a measurement: install 45s, detect 5s, resolve 2s, download about 79s, verify 8s, start 20s, smoke 15s. Sum about 174s. North star is 600s. At 10 Mbps the desk refuses.
