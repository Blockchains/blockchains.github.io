How to use what you bought

  1. Call the endpoint unpaid. It answers 402 with a PAYMENT-REQUIRED quote: $0.005 in USDC on Base to 0x50ab…12fc.
  2. Sign an EIP-3009 USDC authorisation for exactly that amount, send it as PAYMENT-SIGNATURE (v1 sellers: X-PAYMENT) and repeat the same request.
  3. The paid response is the product, shaped like the example above. Keep the PAYMENT-RESPONSE header: it holds the settlement transaction hash, your receipt.
  4. Each call is a separate purchase. Cache the result if you need it again.
